# Changelog

## [2025-10-13] - AI Mature Content Support & Context Handling

### ✅ Изменено

#### AI Service
- **Обработка mature content:**
  - AI теперь обрабатывает ЛЮБОЙ контент, включая нецензурную лексику, mature themes, offensive language
  - Удалены все ограничения на обработку контента
  - Явное указание в system prompts, что это профессиональный инструмент локализации
  - Поддержка игр 18+, фильмов, книг и другого контента для взрослых
  - AI больше НЕ отказывается переводить текст из-за его содержимого

- **Улучшенная обработка контекста:**
  - Контекст теперь воспринимается как **ОБЯЗАТЕЛЬНЫЕ ИНСТРУКЦИИ**, а не просто справочная информация
  - Добавлены яркие маркеры 🔴 и ⚠️ для привлечения внимания AI к mandatory context
  - Явное указание, что контекст может содержать formatting rules, required additions, style requirements
  - Контекст применяется в user prompt И в system content для максимальной эффективности
  - Пример: контекст "Добавляй всегда в конце - пиздец" теперь будет строго выполнен

- **Обновленная документация:**
  - Добавлена секция "Content Policy" в AUTOPILOT_FEATURE.md
  - Явно указано, что инструмент предназначен для профессиональной локализации любого контента
  - Обновлены system prompts во всех функциях: translate, rephrase, shorten, suggest_variants

- **Новые тесты (28 passed ✅):**
  - Добавлен `TestAIServiceMatureContent` класс
  - Тесты проверяют, что AI НЕ отказывается обрабатывать mature content
  - Добавлены тесты на проверку следования mandatory context instructions
  - `test_translate_follows_mandatory_context_instructions` - проверка добавления суффиксов
  - `test_rephrase_follows_mandatory_context_instructions` - проверка стилистических требований
  - `test_suggest_variants_follows_context` - проверка применения контекста ко всем вариантам

### 🎯 Причина изменения

**Проблема 1: Отказ от mature content**
Пользователи не могли переводить контент с нецензурной лексикой, что критично для:
- Игр с рейтингом 18+
- Художественных произведений
- Реалистичных диалогов в играх и фильмах
- Профессиональной локализации контента для взрослых

**Проблема 2: Игнорирование контекста**
AI игнорировал инструкции пользователя в поле "Context". Например:
- Контекст: "Добавляй всегда в конце - пиздец"
- Результат ДО: "Иди на хуй" (контекст проигнорирован)
- Результат ПОСЛЕ: "Иди на хуй - пиздец" (контекст применен)

OpenAI API теперь явно проинструктирован, что его роль - чисто техническая (перевод/улучшение текста), без моральной оценки содержимого, и что контекст содержит обязательные инструкции.

- **Обновленные модели:**
  - `Project` - добавлено поле `team_id` (обязательное), проекты теперь принадлежат командам
  - `User` - добавлены связи с командами (owned_teams, team_memberships, project_access)

**Frontend:**
- **Глобальный селектор команды в header:**
  - Выпадающий список всех команд пользователя
  - Автоматический выбор первой команды при загрузке
  - Сохранение выбора в localStorage
  - Переход на dashboard при смене команды
  - Быстрое создание команды прямо из селектора

- **Новые страницы:**
  - `TeamsPage` - список всех команд пользователя
  - `TeamPage` - детальный просмотр команды с управлением участниками
  - `CreateTeamPage` - форма создания новой команды
  - `EditTeamPage` - редактирование названия и описания команды

- **Компоненты управления командой:**
  - `TeamCard` - карточка команды со счетчиком участников и меню действий
  - `TeamSwitcher` - селектор команды для header
  - `TeamMembersList` - таблица участников с ролями и статусами
  - `AddTeamMemberDialog` - диалог добавления участников по email

#### Функционал управления участниками

- **Добавление участников по email:**
  - Ввод email вручную (без поиска по базе пользователей)
  - Поддержка приглашений несуществующих пользователей
  - Автоматическое создание TeamInvitation для незарегистрированных
  - Мгновенное добавление существующих пользователей

- **Управление ролями:**
  - 5 ролей: admin, editor, viewer, translator, reviewer
  - Изменение роли через dropdown меню
  - Удаление участников с подтверждением
  - Owner не может быть удален или изменен

- **Статусы участников:**
  - **Active** (зеленый) - активные участники команды
  - **Pending Invite** (желтый) - ожидающие приглашения
  - Визуальное различие в таблице (фон, иконки)
  - Бейдж "You" для текущего пользователя

#### Контроль доступа к проектам

- **Двухуровневая система:**
  - Уровень 1: Доступ к команде (TeamMember)
  - Уровень 2: Доступ к конкретному проекту (ProjectAccess)

- **Гранулярный доступ:**
  - Не все участники команды автоматически имеют доступ к проектам
  - Admin команды может выдавать доступ к конкретным проектам
  - Разные роли для разных проектов одной команды

- **Перенос проектов:**
  - Owner проекта может переносить проект между командами
  - При переносе все ProjectAccess удаляются
  - Требуется доступ к обеим командам

#### Безопасность

- **Защита от user enumeration:**
  - Нет endpoint для поиска/перечисления пользователей
  - Добавление участников только по точному email
  - Всегда показывается успех независимо от результата
  - Реальный результат логируется только на backend

- **UUID для публичных ID:**
  - Все teams, projects, users используют UUID
  - Предотвращение brute-force атак
  - Невозможность угадывания ID

- **Проверки доступа:**
  - На уровне сервисов для всех операций
  - Только owner/admin могут управлять командой
  - Детальный контроль доступа к проектам
  - Технические ошибки никогда не показываются пользователям

#### Производительность

- **Apollo Client кэширование:**
  - `cache-and-network` для первого запроса
  - `cache-first` для последующих запросов
  - Минимизация загрузочных спиннеров

- **React оптимизации:**

- **Навигация:**

  - Нет перезагрузок страницы
  - Плавные переходы без мигания
  - Сохранение состояния приложения

#### База данных

- **Новые таблицы:**
